# Tài liệu lịch sử

Đọc `../PROJECT_SPECIFICATION.md`, `../HOAN-THIEN-VA-NGHIEM-THU.md` và hướng dẫn hardware/realtime. Liên kết trong bản lưu có thể còn giữ cấu trúc cũ.
