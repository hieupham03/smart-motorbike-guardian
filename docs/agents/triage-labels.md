# Triage labels

Use these default strings in the `Status:` field of local tickets. They describe readiness, not test results or completion.

| Role | Local status | Meaning |
|---|---|---|
| needs-triage | needs-triage | Work needs evaluation and prioritization. |
| needs-info | needs-info | More information or evidence is required. |
| ready-for-agent | ready-for-agent | Requirements are clear and the agent can perform the work. |
| ready-for-human | ready-for-human | Physical wiring, measurements, board interaction, or another human action is required. |
| wontfix | wontfix | Work is intentionally outside the agreed scope or will not be pursued. |

Track completion separately with `Progress:` when needed. Record actual test outcomes and evidence in the ticket; compilation alone does not prove hardware operation.
